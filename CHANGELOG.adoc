== 0.2.0 — 2026-06-05

=== Ajouté

* **`Ghostscript.to_postscript(input, output, …)`** — convertit un PDF
  en PostScript via le device `gs` `ps2write` (ou `eps2write` avec
  `eps: true`). Options : plage de pages (`first_page`/`last_page`),
  niveau PostScript (2 ou 3), mot de passe. Retourne un `Result`.
* **Binaire `pdftops`** (`src/bin/pdftops.cr`) — équivalent
  poppler-utils, nouvelle cible du shard. `pdftops <doc.pdf>
  [<sortie.ps>]` avec `-o/-f/-l/-e(eps)/-L(niveau)/-p`. Conventions CLI
  ALOLI (`help [<sous-commande>]`, `-h/--help`, `-V/--version`, shorts).
  Loge ici (et non dans le shard `pdf`, pur) parce que c'est un relais
  `gs`, pas une génération PostScript native — cohérent avec la
  stratégie ALOLI de report du rendu.

== 0.1.0 — 2026-05-02

Première version publique.

=== Ajouté

* `Ghostscript.path` / `.available?` / `.version` — détection et
  introspection du binaire `gs`. Path mis en cache après le premier
  lookup ; `.reset_cache!` pour forcer une nouvelle recherche.
* `Ghostscript.compress(input, output, quality:)` — compression PDF
  via `gs -sDEVICE=pdfwrite -dPDFSETTINGS=...`. Cinq presets sous
  forme de Symbol ou d'enum `Quality` : `:screen`, `:ebook`
  *(défaut)*, `:printer`, `:prepress`, `:default`.
* `Ghostscript.run(args)` — échappatoire bas-niveau pour invoquer
  `gs` avec n'importe quels arguments (renvoie un `RunResult` avec
  exit code, stdout, stderr).
* `Ghostscript::Result` — retour structuré des opérations de
  compression : `input_size`, `output_size`, `reduction_percent`,
  `success?`, `to_s` formaté en Ko/Mo et %.
* `Ghostscript::Error` — exception levée quand `gs` n'est pas
  installé ou que le fichier d'entrée est introuvable.
* 20 specs (5 pending sur les machines sans `gs` — testés en CI
  Linux et FreeBSD).
* CI GitHub Actions : format Crystal + ameba + specs sur Linux et
  FreeBSD 15 (avec installation de `ghostscript` dans la matrice).
* README bilingue FR + EN.
